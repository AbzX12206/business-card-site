# Business Card Site (v2): шаблон сайта-визитки

Одна страница для локального бизнеса: Vite + Tailwind CSS 3 + чистый JavaScript.
Демо-контент: стоматология «Harbor Dental Studio». **Все цены, цифры, гарантии и тексты политики — заглушки**, подтвердите их с клиентом.

## 1. Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run preview    # посмотреть сборку
npm test           # юнит-тесты (без браузера)
npx playwright install chromium && npm run test:e2e   # e2e в Chromium
```

Нужен Node 20+. **После правки `src/site.config.js` или словарей перезапустите `npm run dev`**: `index.html` — шаблон, он рендерится на старте.

## 2. Структура

```
src/site.config.js      ← ВСЕ данные клиента: контакты, адрес, часы, услуги, языки, аналитика
src/i18n/en.js, ru.js   ← все тексты (структура словарей одинаковая, это проверяет npm test)
src/i18n/index.js       ← переводчик
src/blocks.js           ← повторяющиеся блоки (услуги, FAQ, часы, отзывы…) и JSON-LD
src/hours.js            ← часы работы и статус «Открыто сейчас»
src/lead.js             ← телефонные маски, валидация, текст для Telegram (общий для браузера и сервера)
src/analytics.js        ← аналитика с согласием
src/main.js             ← поведение страницы
index.html              ← шаблон разметки (токены подставляются при сборке)
build/                  ← плагин Vite, рендер шаблона
functions/api/lead.js   ← серверная функция Cloudflare Pages: приём заявки → Telegram
tests/                  ← unit.test.mjs, e2e.mjs, run-e2e.mjs
.github/workflows/ci.yml, lighthouserc.json
```

Токены в `index.html`: `{{t ключ}}` (перевод), `{{v имя}}` (значение из конфига), `{{block имя}}` (блок), `{{jsonld}}`. Опечатка в ключе или имени **ломает сборку**, а не оставляет дыру на странице.

## 3. Как заменить демо-данные

1. `src/site.config.js`: название, `url` (боевой адрес без `/` на конце), телефон (`display`, `e164`, `country`), WhatsApp, Telegram, Instagram, адрес, `timezone`, `hours`, `services` (id и цена), `currency`, `schemaType`.
2. `src/i18n/en.js` и `ru.js`: тексты. В строках работают `{name}`, `{city}`, `{phone}`, `{telegram}`, `{instagram}`. Названия услуг лежат в `services.items.<id>`.
3. Картинки: `public/assets/hero.svg`, `about.svg` (замените реальными фото, сохранив `width`/`height` в `index.html`), `og.png` (1200×630), `public/favicon.svg`.
4. Блок «Benefits» и FAQ содержат демо-обещания («$0», «2 года гарантии»): перепишите или удалите.
5. Политика конфиденциальности — типовой текст. Покажите юристу.

### Часы работы
`hours: [{ days: [1,2,3,4], open: "08:00", close: "19:00" }, …]`, где `0` = воскресенье. Дни без записи считаются выходными. Бейдж «Открыто сейчас» считается по `timezone` бизнеса, а не посетителя. Работа через полночь не поддерживается (разбейте на два интервала).

### Карта (Google Maps или 2GIS)
- `mapLinkUrl`: ссылка кнопки «Открыть на карте». Пусто = поиск в Google Maps по адресу. Для Казахстана вставьте ссылку на карточку организации в 2GIS. Подпись кнопки в словарях — «Open in Google Maps»: при 2GIS поменяйте `contact.mapOpen` в обоих словарях.
- `mapEmbedUrl`: необязательно, https-адрес для `<iframe>`. Если пусто, показывается только карточка со ссылкой.

### Телефонные маски
`phone.country` — `"US"` или `"KZ"`. Новая страна: добавьте правило в `PHONE_RULES` в `src/lead.js` (маска, код, регулярка валидности) и текст ошибки `form.errorPhone` в словарях (сейчас в нём упомянут номер США).

### Отзывы
Секция появляется **только если `SITE.reviews` не пуст**. Пока реальных отзывов нет, её нет на странице (выдумывать отзывы нельзя). Формат:
```js
reviews: [{ name: "Анна К.", rating: 5, text: { en: "…", ru: "…" }, source: "Google", url: "https://…" }]
```

## 4. Языки

Сейчас EN + RU. Язык выбирается так: сохранённый выбор → язык браузера → `defaultLocale`. HTML собирается на `defaultLocale` (это видят поисковики), остальные языки включаются в браузере без перезагрузки.

**Добавить казахский (или любой язык):**
1. Скопируйте `src/i18n/en.js` → `src/i18n/kk.js`, переведите значения (ключи не трогайте).
2. В `src/i18n/index.js`: `import kk from "./kk.js";` и `export const dictionaries = { en, ru, kk };`.
3. В `src/site.config.js`: `locales: ["en", "ru", "kk"]`.
4. `npm test` проверит, что структура совпадает. Кнопка в шапке появится сама (подпись «ҚАЗ» уже предусмотрена).

> Отдельных URL для языков (`/ru/`) нет, поэтому поисковики индексируют только язык по умолчанию. Если нужен SEO на нескольких языках — это следующий шаг (см. «Что дальше»).

## 5. Заявки: три режима

Режим выбирается автоматически:

| Режим | Когда | Безопасность |
|---|---|---|
| **1. Свой сервер** | задан `VITE_LEAD_ENDPOINT` (или `SITE.leadEndpoint`), например `/api/lead` | токен только на сервере. **Рекомендуется** |
| 2. Прямой Telegram | заданы `VITE_TELEGRAM_BOT_TOKEN` и `VITE_TELEGRAM_CHAT_ID` | токен виден любому посетителю. Только для тестов |
| 3. Демо | ничего не задано | 600 мс «отправка», данные в консоль |

### Режим 1 на Cloudflare Pages
1. Создайте бота у `@BotFather`, узнайте `chat_id` (напишите боту, затем откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`).
2. Pages → проект → Settings → Variables and Secrets: **секреты** `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Либо `wrangler pages secret put TELEGRAM_BOT_TOKEN`.
3. Переменная сборки `VITE_LEAD_ENDPOINT=/api/lead`.
4. Папка `functions/` деплоится вместе с сайтом автоматически.

Что делает `functions/api/lead.js`: проверяет Origin (адрес сайта из `SITE.url` и `ALLOWED_ORIGINS`), тип и размер тела (8 КБ), повторяет валидацию, отбрасывает honeypot, ограничивает частоту (5 заявок за 10 минут с IP), экранирует HTML, отправляет в Telegram с таймаутом, не пишет токен в логи. Сообщение владельцу приходит на языке `ownerLocale`.

Лимит частоты: надёжнее всего привязка Workers Rate Limiting с именем `RATE_LIMITER`; средне — KV с именем `RATE_KV`; без привязок лимит живёт в памяти одного воркера (грубая защита). Ограничения: нет защиты от целенаправленного флуда и капчи; при реальном спаме добавьте Cloudflare Turnstile.

Другой хостинг (Netlify, Vercel): логика в `handleLead(request, env)` — обычная функция `Request → Response`, её можно обернуть под любую платформу.

## 6. Аналитика и согласие

ID задаются в `SITE.analytics` или в `.env`: `VITE_YANDEX_METRIKA_ID`, `VITE_GA4_ID`, `VITE_META_PIXEL_ID`. Пока ID нет, баннера нет и ничего не грузится. Если ID есть: баннер согласия, скрипты грузятся **только после «Принять»**, выбор хранится в `localStorage`, в подвале есть «Настройки cookie» для пересмотра. Цели: звонок, WhatsApp, карта, отправка заявки. ID проверяются по формату (в код-инициализатор попадает только валидное значение).

Юридически (GDPR, закон РК о персональных данных, ФЗ-152) этого недостаточно без вашей политики cookie: текст в словарях типовой.

## 7. Тесты и CI

- `npm test`: 26 юнит-тестов (маски, валидация, часы и часовые пояса, структура словарей, шаблон, экранирование, серверная функция с подменой `fetch`).
- `npm run test:e2e`: собирает сайт, запускает Chromium: меню, FAQ, форма во всех исходах (успех, 429, 500, офлайн, honeypot, двойной клик), переключение языка, бейдж «Открыто» с подменой часов, согласие на аналитику.
- `.github/workflows/ci.yml`: тесты, сборка, e2e, затем Lighthouse CI (`lighthouserc.json`: accessibility и SEO ≥ 0.95 — ошибка, performance и best-practices — предупреждение).

## 8. Мобильная панель и доступность

Под 640 px внизу закреплена панель «Позвонить / WhatsApp / Заявка» (вместо плавающей кнопки). Цвета кнопок и ссылок подобраны под контраст WCAG AA, цели нажатия не меньше 44 px, есть skip-link, нативный `<dialog>`, `prefers-reduced-motion`.

## 9. Что НЕ проверялось при разработке

Окружение разработки было без доступа к npm, поэтому **не запускались**: `vite build`, компиляция Tailwind, Lighthouse, GitHub Actions. Проверено в реальном Chromium на упрощённой сборке (esbuild без CSS) с теми же модулями: вся логика (форма, языки, часы, согласие) и 26 юнит-тестов. Не проверено: внешний вид страницы (вёрстка, цвета, мобильная панель, баннер), тесты, которым нужен CSS (помечены `needsCss` в `tests/e2e.mjs`), и работа функции на живом Cloudflare. После `npm install` запустите `npm run build`, `npm test`, `npm run test:e2e` и просмотрите страницу глазами.
